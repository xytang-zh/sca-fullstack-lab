# CLAUDE.md — docs 设计文档目录

> 本文档面向 AI 编码助手，用于在 `docs/` 目录下工作时提供文档组织约束。
> 工作前**必须**先读取仓库根 [`sca-fullstack-lab/CLAUDE.md`](../CLAUDE.md)。

---

## 1. 目录定位

`docs/` 存放项目设计文档（按编号组织）与需求文档。

```

├── 02-技术栈选型.md
├── 03-GitHub调研.md
├── 04-服务架构设计.md

├── 09-项目需求文档.md

├── 11-数据编码与乱码巡检.md
├── 12-注释规范.md
└── requirements/              需求文档（按服务编号）
```

## 3. 编写规范

1. 新增设计文档**必须**按编号顺序命名（`{NN}-{主题}.md`）
2. 文档**必须**在开头声明适用范围与依赖的上级文档
3. 需求文档**必须**引用具体服务模块
4. 架构决策变更**必须**同步更新根 CLAUDE.md 与对应服务 CLAUDE.md
