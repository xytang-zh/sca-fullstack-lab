### 3.2 Mapping 示例（article）

```json
PUT /article
{
  "settings": {
    "number_of_shards": 3,
    "number_of_replicas": 1,
    "analysis": {
      "analyzer": {
        "ik_pinyin_analyzer": {
          "tokenizer": "ik_max_word",
          "filter": ["pinyin_filter"]
        }
      },
      "filter": {
        "pinyin_filter": {
          "type": "pinyin",
          "keep_first_letter": true,
          "keep_full_pinyin": true
        }
      }
    }
  },
  "mappings": {
    "properties": {
      "id": { "type": "long" },
      "title": { "type": "text", "analyzer": "ik_max_word", "search_analyzer": "ik_smart" },
      "content": { "type": "text", "analyzer": "ik_max_word" },
      "summary": { "type": "text", "analyzer": "ik_max_word" },
      "tags": { "type": "keyword" },
      "category": { "type": "keyword" },
      "author": { "type": "keyword" },
      "status": { "type": "keyword" },
      "publishTime": { "type": "date" },
      "createTime": { "type": "date" },
      "updateTime": { "type": "date" }
    }
  }
}
```

## 6. 关键业务流程

### 6.1 增量同步流程

```
1. portal-service 发布文章
2. 写 MySQL biz_article
3. 发 MQ article.published（含 articleId, action=create/update/delete）
4. search-service 消费：
   - action=create/update：查 MySQL → 写 ES
   - action=delete：删 ES
5. 同步状态写 Redis（计数）
```

### 6.2 全量重建流程

```
1. XXL-JOB 触发 articleSyncToEsJob（每天 2 点）
2. search-service：
   - 创建新索引 article_new
   - 分页拉 MySQL（每页 1000）
   - 批量写入 ES _bulk API
   - 全部完成后切换 alias：
     - 删 alias article → article_old
     - 加 alias article → article_new
     - 删 article_old 索引
3. 失败回滚：保留 article_old
```

## 7. 配置文件

```yaml
server:
  port: 8087

spring:
  elasticsearch:
    uris: http://127.0.0.1:9200
    connection-timeout: 5s
    socket-timeout: 30s
  rabbitmq:
    host: 127.0.0.1
    port: 5672

# 索引配置
search:
  indices:
    - name: article
      shards: 3
      replicas: 1
    - name: knowledge
      shards: 3
      replicas: 1
    - name: operation_log
      shards: 5
      replicas: 1
    - name: ai_message
      shards: 5
      replicas: 1
  sync:
    bulk-size: 1000
    retry-count: 3
```

## 9. 实现要点

| 项 | 要点 |
|----|------|
| 中文分词 | ik_max_word（索引时）+ ik_smart（搜索时） |
| 拼音搜索 | 安装 pinyin 插件 |
| 高亮 | `<em>` 标签，前端 v-html 渲染 |
| 别名切换 | 全量重建用 alias 切换，零停机 |
| 批量写入 | _bulk API，1000 条一批 |
| 失败重试 | Spring AMQP 自动重试 3 次 |
| 深度分页 | 用 search_after 替代 from + size（避免 max_result_window） |
| 字段权重 | multi_match `^3` 提高标题权重 |
