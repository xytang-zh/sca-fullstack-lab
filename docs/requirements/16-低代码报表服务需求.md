# 16 · 低代码报表服务需求（spring-cloud-report）

> 端口 8092，基于 JimuReport 提供在线报表设计器、大屏、打印、导出。

---

## 1. 模块定位

| 维度 | 值 |
|------|-----|
| 服务名 | `spring-cloud-report` |
| HTTP 端口 | 8092 |
| Dubbo 端口 | 20892 |
| 顶级包 | `com.xytang.report` |
| 启动类 | `SpringCloudReportApplication` |
| 角色 | 低代码报表 + 数据大屏 |
| 依赖 | MySQL（JimuReport 元数据）、所有业务库（只读）、Nacos |

| 功能 | 描述 | 业务规则 |

| TDengine 数据集 | 通过 ECharts + 自定义查询 | |

### 2.3 典型报表清单

| 报表 | 数据源 | 用途 |
|------|--------|------|
| 用户增长曲线 | MySQL aurora_system | 按日/周/月统计新增用户 |

| 订单统计报表 | MySQL | 分组汇总（如有电商模块） |

| AI 对话量趋势 | MongoDB aurora_ai | 按日对话数 |
| 文档向量化统计 | PostgreSQL aurora_ai | 知识库文档数 |

### 2.4 大屏模块

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| 综合监控大屏 | 多数据源混合 | MySQL + TDengine + MongoDB |
| 实时刷新 | WebSocket / 定时拉取 | 5s 一次 |
| 多图表 | ECharts 折线/柱状/饼图 | |
| 大屏截图 | 导出 PNG | |

### 2.5 鉴权模块

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| Sa-Token 集成 | 复用 SSO Token | 通过 Gateway 鉴权 |
| 角色控制 | 仅 ADMIN 可访问设计器 | |
| 数据权限 | 按角色限制数据范围 | |

### 2.6 防火墙模块

| 功能 | 描述 | 业务规则 |
|------|------|----------|
| SQL 注入防护 | `sqlInjectionLevel: basic` | |
| 数据源安全 | `dataSourceSafe: true`（生产开启） | |
| 低代码模式 | `lowCodeMode: prod` | |
| 行数限制 | `max-data-rows: 100000` | |

## 6. 关键业务流程

### 6.1 报表设计流程

```
1. 管理员进入报表设计器
2. 选择数据源（如 aurora_system）
3. 写 SQL：SELECT DATE(create_time) AS day, COUNT(*) AS cnt FROM sys_user GROUP BY day
4. 拖拽表格组件到设计区
5. 绑定字段（day → A 列，cnt → B 列）
6. 配置图表（折线图：X=day, Y=cnt）
7. 保存
8. 预览
```

### 6.2 数据大屏流程

```
1. 管理员新建大屏
2. 选择多个数据源（MySQL + TDengine）
3. 拖拽多个图表组件
4. 每个图表绑定不同 SQL
5. 配置实时刷新（5s）
6. 保存为大屏
7. 投屏到监控墙
```

## 7. 配置文件

```yaml
server:
  port: 8092

spring:
  datasource:
    dynamic:
      primary: master
      datasource:
        master:
          url: jdbc:mysql://127.0.0.1:3306/aurora_report
          username: root
          password: xxx

# JimuReport
jeecg:
  jmreport:
    firewall:
      dataSourceSafe: true          # 生产开启
      lowCodeMode: prod
      sqlInjectionLevel: basic
    col: 100
    row: 200
    max-data-rows: 100000
    # Sa-Token 鉴权集成
    sa-token:
      enabled: true
      login-type: server

# 多数据源（复用业务库，只读）
spring.datasource.dynamic.datasource:
  system_master:    # aurora_system
  monitor_tdengine: # aurora_metrics（TDengine）
  ai_mongo:          # aurora_ai
  log_mongo:          # aurora_log
  portal_master:    # aurora_portal
```

## 9. 实现要点

| 项 | 要点 |
|----|------|
| JimuReport 集成 | 用 `jimureport-spring-boot3-starter:2.3.4` |
| NoSQL 数据集 | 加 `jimureport-nosql-starter3` 支持 MongoDB/Redis |
| ECharts 图表 | 加 `jimureport-echarts-starter` |
| TDengine 数据源 | 通过自定义 SQL 查询，不通过 JDBC 数据源 |
| 鉴权 | Sa-Token 集成，复用 SSO Token |
| 生产防火墙 | 必须开启 `dataSourceSafe: true`、`sqlInjectionLevel: basic` |
| 行数限制 | `max-data-rows: 100000`，防止全表扫描 |
| 大屏性能 | 多图表实时刷新，TDengine 查询加索引 |
| 数据权限 | 在 SQL 中加 WHERE 限制数据范围 |
