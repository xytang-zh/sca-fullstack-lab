# 18 · 实施路线图与里程碑

> 本文档给出 13 周实施计划，按周拆解任务，每周对应一份（或多份）需求文档。新手按此顺序执行即可。

---

## 1. 实施原则

1. **先跑起来再深入**：第一周目标只有一个——项目骨架能 `mvn clean install`
2. **垂直切片**：每完成一个功能，要打通"前端 → 网关 → 后端 → 数据库"全链路
3. **不要追求完美**：本项目是学习用，生产级稳定性可后期迭代
4. **善用工具**：Spec-Kit SDD 流程、Arthas、jstack、EXPLAIN
5. **每周复盘 + 写博客**
