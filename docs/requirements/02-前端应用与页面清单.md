# 02 · 前端应用与页面清单

> 本文档列出 3 个前端应用（admin / portal / flow-web）的所有页面、菜单、路由，便于按页面逐个实现。

---

## 1. 前端 Monorepo 总览

```
vue-web-ui/
├── apps/
│   ├── admin/        一体化管理平台（管理员用）
│   ├── portal/       公开门户（公开访客用，SSG）
│   └── flow-web/     工作流子系统（业务用户用）
└── packages/
    ├── ui/           Naive UI 二次封装
    ├── api/          统一 API 调用
    ├── utils/        工具函数
    ├── types/        TS 类型
    └── uno-preset/   UnoCSS 预设
```

### 2.4 admin 路由权限

#### 静态路由（无需鉴权）

```
/login            登录页
/sso/callback     SSO 回调
/error/403 /404 /500 /network
```

#### 动态路由（登录后从后端拉取）

```typescript
// 登录后调用 GET /api/system/menus/routes
// 返回结构：
{
  "path": "/system",
  "name": "system",
  "component": "Layout",
  "meta": { "title": "系统管理", "icon": "settings" },
  "children": [
    {
      "path": "users",
      "name": "system-users",
      "component": "system/user/index",
      "meta": { "title": "用户管理", "icon": "user", "permissions": ["system:user:list"] }
    }
  ]
}

// router/permission.ts 守卫：
router.beforeEach(async (to, from, next) => {
  const userStore = useUserStore();
  if (to.path === '/login') return next();
  if (!userStore.token) return next('/login');
  if (!userStore.userInfo) {
    await userStore.fetchUserInfo();
    const routes = await permissionStore.generateRoutes();
    routes.forEach(r => router.addRoute(r));
    return next({ ...to, replace: true });
  }
  next();
});
```

#### 按钮级权限

```typescript
// v-permission 指令
<button v-permission="'system:user:create'">新增</button>
<button v-permission="'system:user:delete'">删除</button>

// usePermission 组合式函数
const { hasPermission } = usePermission();
if (hasPermission('system:user:create')) { ... }
```

### 3.2 SEO 特性

| 项 | 实现 |
|----|------|
| SSG | Vite SSG 构建时预渲染所有页面 |
| Meta | `@unhead/vue` 自动生成 title/description/og 标签 |
| Sitemap | 构建时生成 `/sitemap.xml` |
| Robots | `/robots.txt` 静态文件 |

## 5. 前端通用规范

### 5.1 页面组件命名

| 类型 | 风格 | 示例 |
|------|------|------|
| 页面 | kebab-case 目录 + `index.vue` | `views/system/user/index.vue` |
| 组件 | PascalCase.vue | `UserList.vue`、`BasicTable.vue` |
| 组合式函数 | camelCase + use 前缀 | `useTable.ts` |

### 5.2 表格页面模板

每个列表页面**必须**用 `BasicTable` + `QueryForm` 模式：

```vue
<template>
  <PageContainer title="用户管理">
    <template #extra>
      <n-button v-permission="'system:user:create'" type="primary" @click="handleCreate">新增</n-button>
    </template>

    <QueryForm :model="query" @search="reload" @reset="reset">
      <n-form-item label="用户名"><n-input v-model:value="query.username" /></n-form-item>
      <n-form-item label="状态"><n-select v-model:value="query.status" :options="statusOptions" /></n-form-item>
    </QueryForm>

    <BasicTable
      :columns="columns"
      :request="pageUsers"
      :query="query"
      ref="tableRef"
    >
      <template #action="{ row }">
        <n-button text @click="handleEdit(row)">编辑</n-button>
        <n-button text @click="handleDelete(row)">删除</n-button>
      </template>
    </BasicTable>

    <UserForm ref="formRef" @success="reload" />
  </PageContainer>
</template>
```

### 5.3 表单页面模板

```vue
<template>
  <BasicForm
    ref="formRef"
    :schema="schema"
    :model="formData"
    :rules="rules"
    @submit="handleSubmit"
  />
</template>

<script setup lang="ts">
const schema = [
  { field: 'username', label: '用户名', component: 'NInput', rules: [{ required: true }] },
  { field: 'status', label: '状态', component: 'NSelect', componentProps: { options: [...] } },
];
</script>
```
