# 03 · 公共模块需求（spring-cloud-common 17 个子模块）

> 本文档定义 17 个公共子模块的职责、对外暴露能力、关键类、使用方式。公共模块是"被依赖的 jar 库"，本身不启动，被业务服务依赖后生效。

---

| # | 模块 | 职责 |

## 5. spring-cloud-common-redisson

### 5.1 对外暴露

#### 5.1.1 注解

| 注解 | 字段 | 用法 |
|------|------|------|
| `@DistributedLock` | name, waitTime, leaseTime | `@DistributedLock(name = "'order:' + #orderId", waitTime = 3, leaseTime = 10)` |
| `@RateLimit` | name, rate, interval | `@RateLimit(name = "login", rate = 5, interval = 1)` 每秒 5 次 |
| `@DelayedQueue` | queueName, delay | 延迟队列 |

#### 5.1.2 切面

```java
@Aspect
@Component
public class DistributedLockAspect {
    @Around("@annotation(distributedLock)")
    public Object around(ProceedingJoinPoint pjp, DistributedLock distributedLock) {
        String key = parseKey(pjp, distributedLock.name());
        RLock lock = redissonClient.getLock(key);
        boolean acquired = lock.tryLock(waitTime, leaseTime, TimeUnit.SECONDS);
        if (!acquired) throw new BusinessException(429, "操作过于频繁");
        try { return pjp.proceed(); }
        finally { if (lock.isHeldByCurrentThread()) lock.unlock(); }
    }
}
```

## 14. spring-cloud-common-log

### 14.1 对外暴露

#### 14.1.1 @OperationLog 注解

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface OperationLog {
    String title();
    BusinessType businessType() default BusinessType.OTHER;
}

public enum BusinessType { INSERT, UPDATE, DELETE, EXPORT, IMPORT, OTHER }
```

#### 14.1.2 AOP 切面

```java
@Aspect
@Component
@RequiredArgsConstructor
public class OperationLogAspect {
    private final EventPublisher eventPublisher;

    @Around("@annotation(operationLog)")
    public Object around(ProceedingJoinPoint pjp, OperationLog operationLog) {
        OperationLogEvent event = new OperationLogEvent();
        event.setTitle(operationLog.title());
        event.setBusinessType(operationLog.businessType());
        event.setMethod(pjp.getSignature().toString());
        event.setArgs(JsonUtils.toJson(pjp.getArgs()));
        event.setUserId(LoginUserContext.get());
        try {
            Object result = pjp.proceed();
            event.setResult(JsonUtils.toJson(result));
            event.setStatus(1);
            return result;
        } catch (Throwable e) {
            event.setStatus(0);
            event.setError(e.getMessage());
            throw e;
        } finally {
            eventPublisher.publish(MqConstants.LOG_OPERATION, event);
        }
    }
}
```

#### 16.1.2 多级缓存查询


### 16.2 缓存问题对策

| 问题 | 方案 |
|------|------|
| 缓存穿透 | 布隆过滤器 + 空值缓存（短 TTL） |
| 缓存击穿 | 互斥锁（Redisson） / 逻辑过期 |
| 缓存雪崩 | TTL 加 ±10% 随机数 + 多级缓存 |
| 数据一致性 | Cache-Aside + 延迟双删 + MQ binlog |

## 17. spring-cloud-common-netty

### 17.1 对外暴露

#### 17.1.1 NettyServer

```java
public class NettyServer implements CommandLineRunner {
    @Override
    public void run(String... args) {
        EventLoopGroup bossGroup = new NioEventLoopGroup(1);
        EventLoopGroup workerGroup = new NioEventLoopGroup();
        ServerBootstrap bootstrap = new ServerBootstrap();
        bootstrap.group(bossGroup, workerGroup)
            .channel(NioServerSocketChannel.class)
            .childHandler(new WebSocketServerInitializer());
        bootstrap.bind(port).sync();
    }
}
```
