# 04 · 网关服务需求（spring-cloud-gateway）

> 端口 8080，统一 API 入口。所有 `/api/**` 请求先经过网关，由网关统一完成路由转发、鉴权、限流、跨域、日志、灰度、文档聚合。

---

## 1. 模块定位

| 维度 | 值 |
|------|-----|
| 服务名 | `spring-cloud-gateway` |
| HTTP 端口 | 8080 |
| 顶级包 | `com.xytang.gateway` |
| 启动类 | `SpringCloudGatewayApplication` |
| 运行模式 | 响应式（Spring WebFlux + Netty） |
| 依赖 | Nacos、Redis（Sa-Token）、Sentinel Dashboard |

> ⚠️ 网关是响应式的，**禁止**使用 Servlet API（`HttpServletRequest`、`@WebFilter`、`Spring MVC`），必须用 `WebFilter`、`ServerHttpRequest`、`WebFlux`。**禁止**依赖 `spring-boot-starter-web`。

## 2. 功能清单

### 2.1 路由转发模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| 路由表加载 | 从 Nacos 拉取 `spring-cloud-gateway.yaml` 配置 | 支持动态刷新 |
| 路径匹配 | `/api/{service}/**` → `{service}` | 用 `Path` 断言 |
| StripPrefix | 剥离 `/api/{service}` 前缀，下游无感知 | `StripPrefix=2` |
| 服务发现 | 通过 Nacos 服务名解析（`lb://service-name`） | 不用自动发现，强制显式路由 |
| WebSocket 路由 | `/ws/{service}/**` 转发到下游 WS 端口 | `lb:ws://service-name` |

### 2.2 鉴权模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| Token 校验 | 从 `Authorization` 头取 Bearer Token，调 `StpUtil.getLoginIdByToken` | Sa-Token Gateway 适配 |
| Token 透传 | 不把 Token 透传下游，改为透传 `X-Login-Id` | 安全考虑 |
| 白名单 | 显式声明匿名路径 | `/api/auth/sso/login`、`/api/portal/**` 等 |
| 401 响应 | Token 无效/过期返回 401 + `R<Void>` | code=40101 过期、40103 未登录 |

### 2.3 限流熔断模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| 路由级限流 | 按 `routeId` 限流 | Sentinel `gw-flow` 规则 |
| 接口级限流 | 按 API 分组 | Sentinel `gw-api-group` |
| IP 限流 | 按客户端 IP | `${remote_addr}` |
| 用户限流 | 按 `X-Login-Id` | 用户级 |
| 降级响应 | 限流命中返回 429 + `R<Void>` | `code=42901` |

### 2.4 跨域模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| CORS 全局配置 | `CorsWebFilter` | 白名单 origin-patterns |
| 预检缓存 | `maxAge=3600` | 减少预检请求 |
| 携带凭证 | `allow-credentials=true` | 必须用 origin-patterns |

### 2.5 日志模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| 请求日志 | method、uri、cost、status | INFO |
| 慢请求标记 | >1s 标记 `[SLOW]` | WARN |
| Trace-Id | 生成 UUID，透传到下游 | `X-Trace-Id` 头 |
| 日志脱敏 | 不打印 Token / 密码 / body | 只打印元数据 |

### 2.6 灰度发布模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| 基于 Header | `X-Gray-Version=v2` 路由到 v2 实例 | 自定义负载均衡 |
| 基于权重 | 30% 流量到 v2 | `WeightedBalancer` |
| 元数据路由 | Nacos metadata `version=v2` | `lb:gray://service-name` |

### 2.7 API 文档聚合模块

| 功能 | 描述 | 实现要点 |
|------|------|----------|
| Knife4j 聚合 | 自动发现服务并聚合 OpenAPI | `knife4j.gateway.enabled=true` |
| 文档地址 | `http://localhost:8080/doc.html` | 仅 dev/test 开放 |
| 生产关闭 | `knife4j.production=true` | 关闭文档 |

## 4. 鉴权过滤器关键代码

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class SaTokenGatewayFilterFactory extends AbstractGatewayFilterFactory<SaTokenGatewayFilterFactory.Config> {

    private final IgnorePathsConfig ignorePathsConfig;

    @Override
    public GatewayFilter apply(Config config) {
        return (exchange, chain) -> {
            ServerHttpRequest req = exchange.getRequest();
            String path = req.getPath().value();

            // 1. 白名单放行
            if (ignorePathsConfig.isIgnored(path)) {
                return chain.filter(exchange);
            }

            // 2. 提取 Token
            String token = req.getHeaders().getFirst("Authorization");
            if (StrUtil.isBlank(token)) {
                return unauthorized(exchange, "Token 缺失", 40103);
            }
            token = token.replace("Bearer ", "");

            // 3. 校验 Token
            Object loginId;
            try {
                loginId = StpUtil.getLoginIdByToken(token);
            } catch (Exception e) {
                return unauthorized(exchange, "Token 无效或已过期", 40101);
            }
            if (loginId == null) {
                return unauthorized(exchange, "Token 无效或已过期", 40101);
            }

            // 4. 透传 X-Login-Id（不透传 Token）
            ServerHttpRequest mutated = req.mutate()
                .header("X-Login-Id", loginId.toString())
                .build();
            return chain.filter(exchange.mutate().request(mutated).build());
        };
    }

    private Mono<Void> unauthorized(ServerWebExchange exchange, String msg, int code) {
        ServerHttpResponse resp = exchange.getResponse();
        resp.setStatusCode(HttpStatus.UNAUTHORIZED);
        resp.getHeaders().setContentType(MediaType.APPLICATION_JSON);
        String body = JsonUtils.toJson(R.fail(code, msg));
        DataBuffer buffer = resp.bufferFactory().wrap(body.getBytes(StandardCharsets.UTF_8));
        return resp.writeWith(Mono.just(buffer));
    }

    @Data
    public static class Config {
        private List<String> excludePaths = new ArrayList<>();
    }
}
```

## 5. CORS 配置

```java
@Configuration
public class CorsConfig {
    @Bean
    public CorsWebFilter corsWebFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOriginPatterns(List.of(
            "https://*.example.com",
            "http://localhost:5173"
        ));
        config.setAllowedMethods(List.of("GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"));
        config.setAllowedHeaders(List.of("*"));
        config.setExposedHeaders(List.of("X-Trace-Id", "Authorization"));
        config.setAllowCredentials(true);
        config.setMaxAge(3600L);

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);
        return new CorsWebFilter(source);
    }
}
```

## 11. 踩坑提示

| 坑 | 解决 |
|----|------|
| 引入 `spring-boot-starter-web` 导致启动失败 | 删除该依赖，只用 `spring-cloud-starter-gateway` |
| 用 `HttpServletRequest` 编译报错 | 用 `ServerHttpRequest` |
| 路由不生效 | 检查 Nacos 配置 dataId 和 group |
| 跨域失败 | 检查 origin-patterns，credentials=true 时不能用 `*` |
| Sentinel 规则不生效 | 检查 Sentinel Dashboard 连接 + dataId |
| Knife4j 文档空白 | 检查下游服务都暴露了 `/v3/api-docs` |
| 灰度不生效 | 检查 Nacos metadata 和 LoadBalancer 配置 |
