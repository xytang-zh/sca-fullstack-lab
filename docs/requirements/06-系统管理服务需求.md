# 06 · 系统管理服务需求（spring-cloud-system）

> 端口 8082，项目"地基"——所有系统级配置、权限、字典都在这里。其他服务通过 Dubbo 调它的接口。

---

## 1. 模块定位

| 维度 | 值 |
|------|-----|
| 服务名 | `spring-cloud-system` |
| HTTP 端口 | 8082 |
| Dubbo 端口 | 20882 |
| 顶级包 | `com.xytang.system` |
| 启动类 | `SpringCloudSystemApplication` |
| 角色 | 系统管理 + 用户/部门/字典中心 + Dubbo Provider |
| 依赖 | MySQL、Redis、Nacos、RabbitMQ |

### 3.2 关键表结构

#### sys_user

```sql
CREATE TABLE sys_user (
    id BIGINT PRIMARY KEY,
    dept_id BIGINT,
    username VARCHAR(50) NOT NULL UNIQUE,
    nickname VARCHAR(50),
    password VARCHAR(100) NOT NULL COMMENT 'BCrypt',
    phone VARCHAR(20),
    email VARCHAR(100),
    avatar VARCHAR(255),
    gender TINYINT DEFAULT 0 COMMENT '0=未知 1=男 2=女',
    status TINYINT DEFAULT 1 COMMENT '0=禁用 1=正常',
    last_login_ip VARCHAR(50),
    last_login_time DATETIME,
    remark VARCHAR(255),
    create_by BIGINT,
    create_time DATETIME,
    update_by BIGINT,
    update_time DATETIME,
    del_flag TINYINT DEFAULT 0,
    INDEX idx_username (username),
    INDEX idx_phone (phone),
    INDEX idx_dept (dept_id)
);
```

#### sys_role

```sql
CREATE TABLE sys_role (
    id BIGINT PRIMARY KEY,
    role_name VARCHAR(50) NOT NULL,
    role_key VARCHAR(100) NOT NULL UNIQUE,
    data_scope TINYINT DEFAULT 1 COMMENT '1=自己 2=本部门 3=本部门及以下 4=全部 5=自定义',
    sort INT DEFAULT 0,
    status TINYINT DEFAULT 1,
    remark VARCHAR(255),
    create_by BIGINT, create_time DATETIME,
    update_by BIGINT, update_time DATETIME,
    del_flag TINYINT DEFAULT 0,
    INDEX idx_role_key (role_key)

```

#### sys_menu

```sql
CREATE TABLE sys_menu (
```

## 6. 业务流程

### 6.1 用户创建流程

```
1. 管理员进入用户管理 → 点"新增"
2. 填写表单：用户名、姓名、密码、手机、邮箱、部门、岗位、角色、状态
3. 前端 POST /api/system/users（数据校验：用户名唯一）
4. 后端：
   - 校验用户名唯一
   - 密码 BCrypt 加密
   - 写 sys_user
   - 写 sys_user_role（角色关联）
   - 写 sys_user_post（岗位关联）
   - 清除用户列表缓存
   - 发 MQ user.update（其他服务订阅刷新缓存）
5. 返回 R<UserVO>
6. 前端刷新列表
```

### 6.2 前端动态路由生成流程

```
1. 前端登录成功
2. 调 GET /api/system/users/me/menus
3. 后端：
   - 从 X-Login-Id 取 userId
   - 查 sys_user_role → role_id 列表
   - 查 sys_role_menu → menu_id 列表
   - 查 sys_menu（按 menu_id 列表 + 父子关系组装树）
4. 返回菜单树（含 path/component/perms/icon）
5. 前端 router/permission.ts：
   - 拉取后调用 addRoute 注入
   - 生成菜单
6. 进入首页
```

### 6.3 数据权限流程

```
1. 用户 A（角色：部门经理，data_scope=3 本部门及以下）查询用户列表
2. 后端 @DataScope 注解拦截
3. SQL 自动追加：
   WHERE d.id IN (
     SELECT id FROM sys_dept
     WHERE FIND_IN_SET(id, (
       SELECT ancestors FROM sys_dept WHERE id = (dept_id of A)
     )) OR id = (dept_id of A)
   )
4. 只返回本部门及子部门的用户
```

## 8. 与其他服务的关系

| 上游 | 下游 | 关系 |
|------|------|------|
| Gateway | system | HTTP 转发 |
| 所有业务服务 | system | Dubbo RPC（查用户、部门、字典） |
| system | message | MQ `user.update`（用户变更通知） |
| system | log | MQ `log.operation`（操作日志） |
| system | Redis | 字典缓存、用户缓存、参数缓存 |

## 9. 实现要点

| 项 | 要点 |
|----|------|
| 密码加密 | BCrypt cost=10 |
| 用户名唯一 | 数据库唯一索引 + 业务校验 |
| 部门 ancestors | 用逗号分隔的父级链，如 `0,1,2` |
| 菜单树构建 | 一次性查全量，内存组装（避免 N+1） |
| 字典缓存 | Caffeine + Redis 多级缓存 |
| 数据权限 | SQL 拦截器自动追加 WHERE |
| Excel 导入 | EasyExcel + 监听器 |
| 软删除 | del_flag 字段 + MyBatis-Plus @TableLogic |
| 雪花 ID | MyBatis-Plus 默认 IdentifierGenerator |
