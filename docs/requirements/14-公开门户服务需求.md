## 3. 数据模型

### 3.1 MySQL 表

```sql
CREATE TABLE biz_article (
    id BIGINT PRIMARY KEY,
    title VARCHAR(200),
    slug VARCHAR(200) UNIQUE COMMENT 'URL 友好',
    summary VARCHAR(500),
    content LONGTEXT COMMENT 'Markdown',
    content_html LONGTEXT COMMENT '渲染后 HTML',
    cover_image VARCHAR(500),
    author_id BIGINT,
    category_id BIGINT,
    tags VARCHAR(500) COMMENT '逗号分隔',
    view_count INT DEFAULT 0,
    is_top TINYINT DEFAULT 0,
    is_recommend TINYINT DEFAULT 0,
    status TINYINT DEFAULT 1 COMMENT '0=草稿 1=已发布 2=下架',
    publish_time DATETIME,
    seo_title VARCHAR(200),
    seo_description VARCHAR(500),
    seo_keywords VARCHAR(200),
    create_time DATETIME,
    update_time DATETIME,
    del_flag TINYINT DEFAULT 0,
    INDEX idx_slug (slug),
    INDEX idx_status_time (status, publish_time),
    INDEX idx_category (category_id)
);

CREATE TABLE biz_category (
    id BIGINT PRIMARY KEY,
    name VARCHAR(50),
    slug VARCHAR(50) UNIQUE,
    parent_id BIGINT DEFAULT 0,
    sort INT DEFAULT 0,
    INDEX idx_parent (parent_id)
);

CREATE TABLE biz_tag (
    id BIGINT PRIMARY KEY,
    name VARCHAR(50) UNIQUE,
    slug VARCHAR(50) UNIQUE,
    use_count INT DEFAULT 0
);

CREATE TABLE biz_news (
    id BIGINT PRIMARY KEY,
    title VARCHAR(200),
    slug VARCHAR(200) UNIQUE,
    summary VARCHAR(500),
    content LONGTEXT,
    column_id BIGINT,
    cover_image VARCHAR(500),
    status TINYINT DEFAULT 1,
    publish_time DATETIME,
    create_time DATETIME, update_time DATETIME
);

CREATE TABLE biz_news_column (
    id BIGINT PRIMARY KEY,
    name VARCHAR(50),
    slug VARCHAR(50) UNIQUE,
    sort INT DEFAULT 0
);

CREATE TABLE biz_product (
    id BIGINT PRIMARY KEY,
    name VARCHAR(100),
    slug VARCHAR(100) UNIQUE,
    summary VARCHAR(500),
    content LONGTEXT,
    cover_image VARCHAR(500),
    images TEXT COMMENT 'JSON 数组',
    specs TEXT COMMENT 'JSON 规格',
    price DECIMAL(10, 2),
    status TINYINT DEFAULT 1,
    sort INT DEFAULT 0,
    create_time DATETIME, update_time DATETIME
);

CREATE TABLE biz_link (
    id BIGINT PRIMARY KEY,
    name VARCHAR(50),
    url VARCHAR(255),
    logo VARCHAR(500),
    sort INT DEFAULT 0,
    status TINYINT DEFAULT 1
);
```

## 6. 关键业务流程

### 6.1 文章发布流程

```
1. 管理员写文章（Markdown）
2. POST /portal-admin/articles
3. portal-service：
   - 保存 biz_article（status=0 草稿）
   - 生成 slug（如 my-first-post）
   - 渲染 Markdown → HTML（content_html）
   - 自动生成 SEO Meta
4. 管理员点"发布"
   - PATCH /portal-admin/articles/{id}/status?status=1
   - 设置 publish_time
   - 发 MQ article.published → search-service 同步 ES
5. 前端访问 GET /portal/articles/{slug}
   - 查 biz_article where slug=?
   - 阅读量 +1（Redis INCR）
   - 返回
```

### 6.2 Sitemap 自动生成

```
1. 每天凌晨 XXL-JOB 触发 sitemapJob
2. 查所有 status=1 的文章/新闻/产品
3. 生成 /portal/sitemap.xml
4. 提交到 Google Search Console / Bing Webmaster
```

```yaml
    enabled: true
```

## 9. 实现要点

| 项 | 要点 |
|----|------|
| URL 友好 | 用 slug 而非 ID，slug 唯一索引 |
| Markdown 渲染 | 后端预渲染 HTML，前端直接显示 |
| 阅读量 | Redis INCR 后定时同步 DB |
| 缓存 | 文章详情 + 列表多级缓存 |
| SEO Meta | 用 @unhead/vue 前端动态生成（SSG 时预渲染） |
| Sitemap | 每天自动生成 + 自动提交 |
| 阅读量防刷 | IP + 5 分钟内同一文章只计 1 次 |
| 全文搜索 | 调 search-service |
| 公开接口不鉴权 | 只读 + 状态=已发布 |
